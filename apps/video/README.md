# Astro Stack video

Remotion source for Astro Stack product videos. There are three compositions:

- `AstroStackPromo`: a 30-second, 1920×1080, 60 fps launch video. Kinetic
  headlines, the CLI answering prompts in a terminal, and the integration picks.
- `AstroStackTerminal`: a 16-second, 1440×1440, 60 fps loop of a real CLI
  session drawn on a character grid. The last frame leads straight into the first.
- `AstroStackCliDemo`: a 46-second, 1280×720, 30 fps terminal demo of a
  marketing project being created.

## Commands

Start the Remotion studio:

```sh
pnpm --filter @astro-stack/video dev
```

Render the CLI demo:

```sh
pnpm --filter @astro-stack/video render:cli-demo
```

The rendered MP4 is written to `out/astro-stack-cli-demo.mp4`.

## Promo and terminal videos

Both use Mixkit #694 "House Two" (Mixkit Stock Music Free License) at 120 BPM,
and every cut, keystroke and pick lands on a measured beat. Each frame is
computed from the frame number alone. Animated values come from
`springTrack` in `src/lib/remocn-ui/timeline.ts`, which adds up one closed-form
spring per change, so scrubbing to any frame in the studio shows exactly what
renders.

The terminal glyphs and prompt layout copy `@clack/prompts` 1.7, the version
the CLI depends on. If the CLI's prompts or copy change, update
`src/terminal/session.ts` and `src/promo/TerminalCli.tsx` to match.

### Music

The music files are gitignored, so a fresh clone can't render the promo or
terminal video until you add the track:

1. Download "House Two" from https://mixkit.co/free-stock-music/tag/house/
   (Mixkit #694, direct file `https://assets.mixkit.co/music/694/694.mp3`).
2. Save it as `public/audio/house-two.mp3`.
3. Run the audio script below. It cuts `promo-music.wav` and
   `terminal-music.wav` from that file.

The UI sounds in `public/audio/sfx/` are generated by `scripts/make-sfx.py`
and are committed.

To re-measure the beat grids and rebuild the UI sounds you need Python 3,
numpy and ffmpeg:

```sh
pnpm --filter @astro-stack/video audio
```

This writes `src/promo/beats.json`, `src/terminal/beats.json` and
`src/shared/sfx.json`, which the compositions import. Render them to `out/`:

```sh
pnpm --filter @astro-stack/video render:promo
pnpm --filter @astro-stack/video render:terminal
```
